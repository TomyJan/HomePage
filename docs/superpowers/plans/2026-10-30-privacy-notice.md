# 隐私政策与底部告知实现计划

> **面向 AI 代理的工作者：** 使用 executing-plans 逐任务实现，重要行为先验证 RED → GREEN。用户已要求信息确认后独立完成开发、审查与本地预览，无需重复询问执行方式。

**目标：** 提供页脚和底部告知双入口的隐私政策弹窗，以及可直接访问的纯静态隐私政策页面。

**架构：** Astro 复用政策正文组件；主页用原生 dialog，独立 /privacy.html 以同款弹窗面板展示正文。浏览器只记录告知版本，确认状态与现有统计互不影响。

**技术栈：** 当前 Astro / TypeScript、CSS、原生 dialog、localStorage，不新增依赖。

**规格：** docs/design/specification.md 与下列已确认设计。

## 已确认设计

- “知道了”只表示已知晓告知，保留现有访问统计，不代表统计授权或同意其他信息处理。
- 左下页脚加入“隐私政策”；窄屏折叠顺序为站点地图、服务状态、隐私政策，版本始终保留。
- 底部深色轻量告知条于页面入场后显示。确认后淡出并保存版本；政策更新后重新告知。存储不可用时本次仍能关闭，不阻断主页。
- 政策弹窗有开关动画、内部滚动、可见关闭按钮、Esc、背景关闭与焦点恢复。打开政策不确认告知，不重置或暂停视频。
- 正文采用易懂中文，说明基本访问、必要存储、信息使用与保护、外部链接、权利联系和更新；不列技术实现、虚构保存天数、绝对免责或概括同意条款。
- 独立页面无脚本仍可阅读；首页无脚本时页脚链接直接访问独立页。
- 告知条出现期间为底部链接和媒体按钮留出空间，关闭后恢复原布局；隐藏 UI 模式一并隐藏告知，不影响播放器。

## 全局约束

- 直接在 master 工作，不新建分支；提交保留中文 Conventional Commits 和签名。
- 保持视频优先、MiSans、35% 头像圆角和冻结 v3 不变；不改变既有统计、媒体重试与站点正文。
- 不自动发布托管平台；最后启动 4321 开发实例并在内置浏览器打开供检查。

## 审查重点

- 浏览器拒绝存储、旧版本或损坏值时，主页和确认按钮仍可使用。
- 页脚链接移入“更多”后，弹窗入口仍工作，关闭后焦点不留在隐藏节点。
- 弹窗与 HostLoc 来源提示、Esc、隐藏 UI 相互独立，视频持续播放。
- 320px、390px 和短横屏下告知、关闭按钮及政策正文均可到达，无水平溢出。
- 正文不承诺未经核实的统计能力、保存时长、第三方行为或法律合规结论。
