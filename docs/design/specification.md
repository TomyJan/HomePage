# 主页正式实现规格

本文件描述当前实现要求；冻结的 `prototypes/video-first-v3.html` 提供视觉基线，未包含的行为以本规格为准。其他已批准快照见 [设计资产说明](README.md)，不作为当前开发指引。用户明确要求优先。

## 视觉与内容

二次元、清爽、现代、简约、高效，略带科技感。视频优先，内容集中于左下角，右上留白。中性深色，文字阴影和到边缘完全透明的局部渐变保障可读性，不铺满屏遮罩。全部文字使用 MiSans。

正式网页标题为“荼蘼 TomyJan - 个人主页与官方网站”，描述为“TomyJan 的个人主页与官方网站，提供博客文章、服务导航及联系信息。”。元信息集中在 `src/data/site.ts#siteMetadata`，Open Graph 使用同一标题和描述；canonical 与 Open Graph URL 指向 Astro 配置中的正式主域。冻结原型保留历史元信息，不作为 SEO 文案基准。

左上为旧头像与“荼蘼 TomyJan”。favicon、加载壳和左上角同一头像，35% 大圆角矩形。正式站直接引用旧版 `https://public-cdn.tomys.top/head.png`，地址集中于 `resources.avatar`，不托管本地头像副本。页面头像用 CSS 圆角；favicon 复用载入的跨域原图，在浏览器异步裁剪为透明圆角 PNG，不阻塞入场；无脚本时保留 CDN 原图图标。冻结原型中的本地图片仅供历史设计对照，不随此改动更新。

左上中英文使用同一字号、字重和字距，之间仅一个普通空格。页脚“备案信息/更多”继承同一文字阴影；右侧媒体图标使用单次、局部清晰的投影。正常页脚不绘制椭圆渐变或背景暗斑，底部整条渐变只在隐藏 UI 时出现。

服务与联系的子卡片使用单个黑色最高约 12% 透明度的独立衬底，尺寸与圆角跟随实际卡片组，仅对该实心背景做一次 8px 柔化。阴影从卡片组边界内侧开始衰减，向外自然消失，不使用满强度矩形加窄边渐变。核心透明度不随卡片数量、位置或间隙叠加。禁止独立卡片阴影或按整组子元素轮廓生成模糊投影；卡片、文字和视频本身保持清晰。柔化范围留在既有阴影留白中，不改变布局。布局的底对齐容器与实际卡片网格分离，联系卡片较少时不把衬底延伸到上方空白区。不添加整体卡片背景或边框。左侧四个导航按钮投影比卡片组更浅：常态约 5%，悬停和选中约 7%，偏移及扩散保持紧凑。

首页介绍与文章列表的衬底只沿可见字形轮廓轻微扩张、柔化，短句后方与段间空白保持透明，不给整个内容框铺背景。每个文字区先将全部可见文字合并为一个 alpha 轮廓，排除淡色分隔线、控件底色及边框，再以最高 14% 透明度统一着色；密集文字和相邻行不会重复叠黑。标题、正文、动态文章及固定底部链接自动跟随换行、滚动和字体变化，无脚本时也可显示。字形仍用 `0 1px 2px` 轻投影增强清晰度，不使用大范围文字模糊或径向暗斑。

所有弹出式与悬浮表面都在外缘四周绘制轻量黑色阴影，水平、垂直偏移均为零，低透明度、小扩张，随距离向外渐隐。页脚弹层、隐私与来源弹窗、独立政策面板及底部告知共用标准档，媒体状态消息和按钮悬浮提示共用紧凑档，参数集中在 `src/styles/elevation.css`。阴影不计入布局，不扩大背景遮罩或模糊视频，不改变告知的 12px 底边间距；滚动仅裁切内部内容，保留浮层外缘阴影与页脚三角。

左下四个纵向入口：首页、服务导航、博客文章、联系支持。首页默认展开，可点击当前入口关闭；打开、关闭、切换均有动画。没有大卡片外框、换边按钮或额外折叠说明。服务和联系仅有子卡片。

## 尺寸和滚动

所有面板视口同高，约四行子卡片；桌面 310px、移动 296px，并受屏高限制。子卡片桌面 58px、移动 56px。内容宽 402px，随视口缩小；容器宽不超过 270px 时改为一列。内容较少靠下，内容多从顶部滚动。真实内容底边与最后一个导航按钮底边对齐。

正常尺寸保留定稿效果。高度不超过 570px 时，按 dock、品牌预留及底部安全区压缩导航，按钮至少 24px；349px 与 273px 以下进一步收紧间距。高度小于 440px 时，舞台按实际视口高度显示。内容、滚动指示和页脚仍须可达，字体迟到后重新计算对齐与收纳。

滚动区上下 24px、左右 30px 阴影留白，不计入真实内容对齐。滚动内容上下渐隐；滚动指示条在按钮右侧、内容左侧，轨道透明，仅显示滑块，不能拖动，整个指示条上下与导航按钮组严格对齐。各页滚动位置保留。

## 加载与视频

深色加载壳先于外部资源显示。至少显示 1200ms，MiSans 等待上限 1800ms。CSS/必要脚本与字体之外的资源不影响正文入场。图片、视频、文章接口、统计均异步，失败时主页仍可使用。减少动态效果偏好缩短过渡、禁止自动播放，仍保留手动播放。

无 JavaScript 时加载层隐藏，首页介绍和静态链接直接可见且可用；不显示依赖脚本的导航、播放器按钮、计时和备案弹层入口。默认静态 HTML 不给介绍或页脚添加 `inert`，同步内联脚本在模块初始化前启用加载门禁，正常入场后解除。`noscript` 样式优先级须高于后续全局 CSS。

保留旧站三视频地址，见 `src/data/site.ts`。每次页面初始化仅随机一次，之后同一 video 元素循环该视频。结束、换页、隐藏 UI 不换视频，不重新挂载，不改变用户暂停状态。刷新才重新随机。默认静音、内联播放；自动播放被拒绝时允许手动播放。错误不自动随机重选。

随机动漫兜底图 `https://api.tomys.top/api/acgimg` 异步加载，放在视频下方；视频与图片未就绪或都失败时保持纯黑。视频、兜底图和 UI 使用明确的非负分层；收到实际视频帧后再显示画面。无视频、减少动态效果、真实视频失败时图片仍可见，不让图片阻塞加载壳。

等待/缓冲和没有原生 MediaError 的错误通知不撤下已显示的视频。真实网络或解码错误先暂停视频，避免隐藏画面后音频仍播放；最多自动重载同一地址两次，恢复播放位置、静音与音量，保留用户暂停意图，不重新随机。首次播放请求被重载中止时，旧请求不得取消当前恢复意图。连续稳定播放 30 秒后恢复自动重试额度，暂停、等待或停滞会中断稳定计时；持续失败时保留兜底并允许用户点击播放重试。

自动重载耗尽后仍保存中断前的播放位置，手动重试继续使用该位置；只有成功重载后才清除待恢复位置，不能从已被 `load()` 清零的元素重新取值。

右下三个简洁按钮按播放/暂停、静音/取消静音、隐藏/恢复排列，边距与左下统一，使用足够清晰的局部图标阴影，图标切换动画。窄屏不折叠媒体按钮。

背景视频是装饰层，不提供原生控制栏、下载/全屏控制入口、画中画、远程播放或拖拽入口，不参与键盘聚焦。整个页面保留浏览器原生右键菜单，禁止拦截或取消 `contextmenu`，包括空白背景和隐藏 UI 模式。视频设为 `inert` 且不接收指针事件，上方放置无事件处理的透明普通元素，让浏览器的右键命中页面而非视频。保留元素级媒体属性限制与自定义三个控制按钮。

隐藏模式：其余 UI 消失，仅剩播放器底部黑色渐变与右侧按钮。鼠标移动唤醒；在底部工具栏内悬停或键盘聚焦时保持显示，否则 1000ms 后渐隐。触摸可唤醒，Esc 恢复。键盘与触屏都可操作。

首次触摸隐藏按钮后，无需再次触摸背景就应启动 1000ms 休眠计时。悬停只跟踪真实鼠标或笔的指针进入/离开，忽略触摸兼容 `:hover`；桌面悬停与键盘焦点保持规则不变。

仅隐藏模式绘制整条加高、加深的底部渐变；绘制范围不扩大悬停保持区域，也不改变控制按钮位置。

## 博客

首次打开才访问 WordPress REST API，每页 10 篇，正常分页可连续加载至末页；空页、无有效文章或全重复页安全停止，避免无界请求。文章日期和真实标题保留，面板内不重复写“博客文章”标题。ID 去重，12s 超时、失败重试、加载动画；切换页保留已加载内容和位置。接口标题按纯文本解码，外链仅允许 http/https。

底部链接固定在列表外，与导航底边对齐。加载中为“去博客读更多”；全部完成为“已加载全部 N 篇, 去博客读”，N 为实际加载量。不要额外显示“没有更多了”。零篇或接口错误有可理解的状态且仍能去博客。

## 隐私政策与底部告知

提示仅作告知，“知道了”不改变统计行为，不代表概括同意信息处理。当前展示站不新增用户协议。

页脚链接行增加“隐私政策”，同时在底部 Cookie 与隐私提示中提供入口。窄屏沿用“更多”，折叠顺序为站点地图、服务状态、隐私政策，版本始终在外。两个入口在主页打开同一个原生 dialog；链接保留独立 privacy.html 地址，可直接访问，无脚本时也可阅读。独立页采用同款深色浮层面板样式。

政策正文与更新日期集中于 site.ts，使用易懂中文说明浏览、必要存储、基本访问信息的使用与保护、外部资源、权利联系和更新。不描述内部工具或存储接口，不虚构具体保存天数，不宣称绝对安全、全面免责或自动取得授权。联系方式沿用现有联系支持。

告知只在加载入场后以独立浮层显示，距视口底边保留 12px 悬浮间距，设备安全区仅增加提示内部留白，保留 MiSans、低饱和深色和细边界；不占布局高度，不改变品牌、导航、内容、页脚或媒体按钮的位置与尺寸，也不隐藏运行时长。文字说明 Cookie 及类似技术的用途，将“隐私政策”链接融入正文；右侧仅保留“知道了”，不写“您的选择”等暗示统计授权选择的措辞。窄屏与短屏仅调整浮层自身宽度、间距和字号，不为页脚或媒体操作预留抬高空间，页脚弹层显示在告知之上。确认后淡出；隐藏 UI 模式一并隐藏。确认状态保存为本地告知版本，更新版本后重新提示；限制存储时本次仍可关闭，不影响浏览。

政策弹窗仅保留固定的标题、更新日期与关闭按钮，正文内部滚动；不显示眉题或底部说明、返回按钮。独立政策页同步精简，保留顶部返回主页链接；页面自身使用 border-box，将留白计入视口高度，仅正文内部滚动，不引入外层滚动条。打开与关闭均有过渡；支持键盘焦点约束、Esc、关闭按钮、背景点击和返回入口。打开政策本身不确认提示，也不暂停、重载或重新选择背景视频。减少动态效果时缩短动画。冻结 v3 与历史图片、摘要保持不变；既有视觉回归在真实确认告知后核对原布局。
