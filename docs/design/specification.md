最终批准：2026-10-27，含正式开发后的用户修订。本文件与冻结的 `prototypes/video-first-v3.html` 一起构成当前实现基线；初次定稿及 v2 仅保留历史。用户后续明确要求优先。

## 视觉与内容

正式网页标题为“荼蘼 TomyJan - 个人主页与官方网站”，描述为“TomyJan 的个人主页与官方网站，提供博客文章、服务导航及联系信息。”。元信息集中在 `src/data/site.ts#siteMetadata`，Open Graph 使用同一标题和描述；canonical 与 Open Graph URL 指向 Astro 配置中的正式主域。冻结原型保留历史元信息，不作为 SEO 文案基准。

左上中英文使用同一字号、字重和字距，之间仅一个普通空格。页脚“备案信息/更多”继承同一文字阴影；右侧媒体图标使用单次、局部清晰的投影。正常页脚不绘制椭圆渐变或背景暗斑，底部整条渐变只在隐藏 UI 时出现。

服务与联系的子卡片使用单个黑色 20% 透明度阴影层，阴影核心覆盖实际卡片组，向外 18px 线性渐隐到完全透明；横纵遮罩取交集。核心透明度不随卡片数量、位置或间隙叠加。禁止独立卡片阴影或按整组子元素轮廓生成模糊投影。布局的底对齐容器与实际卡片网格分离，联系卡片较少时不把阴影延伸到上方空白区。不添加整体卡片背景或边框。

左下四个纵向入口：首页、服务导航、博客文章、联系支持。首页默认展开，可点击当前入口关闭；打开、关闭、切换均有动画。没有大卡片外框、换边按钮或额外折叠说明。服务和联系仅有子卡片。

## 尺寸和滚动

所有面板视口同高，约四行子卡片；桌面 310px、移动 296px，并受屏高限制。子卡片桌面 58px、移动 56px。内容宽 402px，随视口缩小；容器宽不超过 270px 时改为一列。内容较少靠下，内容多从顶部滚动。真实内容底边与最后一个导航按钮底边对齐。

正式实现保留正常尺寸的定稿效果。手机横屏高度小于 440px 时，舞台按实际视口高度显示，避免原型最小高度裁掉控制栏与页脚。字体迟到后需重新计算滚动指示和对齐。

滚动区上下 24px、左右 30px 阴影留白，不计入真实内容对齐。滚动内容上下渐隐；滚动指示条在按钮右侧、内容左侧，轨道透明，仅显示滑块，不能拖动，整个指示条上下与导航按钮组严格对齐。各页滚动位置保留。

## 加载与视频

深色加载壳先于外部资源显示。至少显示 1200ms，MiSans 等待上限 1800ms。CSS/必要脚本与字体之外的资源不影响正文入场。图片、视频、文章接口、统计均异步，失败时主页仍可使用。减少动态效果偏好缩短过渡、禁止自动播放，仍保留手动播放。

无 JavaScript 时加载层隐藏，首页介绍和静态链接直接可见且可用；不显示依赖脚本的导航、播放器按钮、计时和备案弹层入口。默认静态 HTML 不给介绍或页脚添加 `inert`，同步内联脚本在模块初始化前启用加载门禁，正常入场后解除。`noscript` 样式优先级须高于后续全局 CSS。

保留旧站三视频地址，见 `src/data/site.ts`。每次页面初始化仅随机一次，之后同一 video 元素循环该视频。结束、换页、隐藏 UI 不换视频，不重新挂载，不改变用户暂停状态。刷新才重新随机。默认静音、内联播放；自动播放被拒绝时允许手动播放。错误不自动随机重选。

开发阶段用户补充：保留旧随机动漫兜底图 `https://api.tomys.top/api/acgimg`，异步加载，放在视频下方；视频与图片未就绪或都失败时保持纯黑，移除设计阶段占位山景与配色。视频、兜底图和 UI 使用明确的非负分层；收到实际视频帧后再显示画面。无视频、减少动态效果、真实视频失败时图片仍可见，不让图片阻塞加载壳。

等待/缓冲和没有原生 MediaError 的错误通知不撤下已显示的视频。真实网络或解码错误先暂停视频，避免隐藏画面后音频仍播放；最多自动重载同一地址两次，恢复播放位置、静音与音量，保留用户暂停意图，不重新随机。首次播放请求被重载中止时，旧请求不得取消当前恢复意图。连续稳定播放 30 秒后恢复自动重试额度，暂停、等待或停滞会中断稳定计时；持续失败时保留兜底并允许用户点击播放重试。

自动重载耗尽后仍保存中断前的播放位置，手动重试继续使用该位置；只有成功重载后才清除待恢复位置，不能从已被 `load()` 清零的元素重新取值。

右下三个简洁按钮按播放/暂停、静音/取消静音、隐藏/恢复排列，边距与左下统一，使用足够清晰的局部图标阴影，图标切换动画。窄屏不折叠媒体按钮。

背景视频是装饰层，不提供原生控制栏、下载/全屏控制入口、画中画、远程播放或拖拽入口，不参与键盘聚焦。整个页面保留浏览器原生右键菜单，禁止拦截或取消 `contextmenu`，包括空白背景和隐藏 UI 模式。视频设为 `inert` 且不接收指针事件，上方放置无事件处理的透明普通元素，让浏览器的右键命中页面而非视频。保留元素级媒体属性限制与自定义三个控制按钮。

隐藏模式：其余 UI 消失，仅剩播放器底部黑色渐变与右侧按钮。鼠标移动唤醒；在底部工具栏内悬停或键盘聚焦时保持显示，否则 1000ms 后渐隐。触摸可唤醒，Esc 恢复。键盘与触屏都可操作。

首次触摸隐藏按钮后，无需再次触摸背景就应启动 1000ms 休眠计时。悬停只跟踪真实鼠标或笔的指针进入/离开，忽略触摸兼容 `:hover`；桌面悬停与键盘焦点保持规则不变。

隐藏模式的底部渐变比常规工具栏更高、更深；只扩展绘制范围，不扩大悬停保持区域，也不改变控制按钮位置。

## 博客

首次打开才访问 WordPress REST API，每页 10 篇，可连续加载所有文章。文章日期和真实标题保留，面板内不重复写“博客文章”标题。ID 去重，12s 超时、失败重试、加载动画；切换页保留已加载内容和位置。接口标题按纯文本解码，外链仅允许 http/https。

底部链接固定在列表外，与导航底边对齐。加载中为“去博客读更多”；全部完成为“已加载全部 N 篇, 去博客读”，N 为实际加载量。不要额外显示“没有更多了”。零篇或接口错误有可理解的状态且仍能去博客。

## 资源、构建与迁移

正式框架 Astro + TypeScript，纯静态，无 SSR、后端或前端框架运行时。CSS 与浏览器动画 API 复用定稿。开发服务器启动或生产构建时读取完整 Git SHA，展示前 7 位，提交链接使用全 SHA。可由 CI 提供；浏览器不请求 GitHub。每次构建固定版本，重新构建才变化。
