# 验收清单

本文说明当前实现的验证方法。历史执行日志、测试数量和设计探索不在文档中累积；具体结果查看对应提交与 CI。行为要求见 [正式规格](design/specification.md)，开发方式见 [开发说明](development.md)。

## 自动化门禁

使用 `.nvmrc` 与 `package.json#packageManager` 指定的工具链：

```sh
corepack pnpm install --frozen-lockfile
corepack pnpm exec playwright install chromium
corepack pnpm verify
corepack pnpm test:e2e
```

- `verify` 执行格式、Astro/TypeScript、单元测试、静态构建和产物校验。任何一步失败都应修复后重新验证。
- 产物检查涵盖四个静态页面、爬虫资源、完整提交版本、单视频元素、旧入口重定向、冻结设计摘要与全部客户端 JavaScript 的 gzip 总量（小于 25,000 字节）。
- 浏览器用例重新构建 `dist/`，通过测试静态服务运行 Chromium。外部资源使用受控夹具，真实统计不发送；这不等同于外网或实体设备验收。
- CI 另执行生产依赖高危审计，并保存构建产物与浏览器报告。配置以 `.github/workflows/code-check.yml` 为准，产物和报告不提交到仓库。

## 回归范围

| 范围                                                          | 主要测试                            |
| ------------------------------------------------------------- | ----------------------------------- |
| 域名、版本、无 Git 产物校验、页脚收纳、运行时长、文章数据校验 | `tests/unit/`                       |
| 无脚本降级、加载壳、导航、博客分页、隐藏 UI                   | `tests/e2e/homepage.spec.ts`        |
| 桌面与窄屏的冻结原型对照                                      | `tests/e2e/design.spec.ts`          |
| 卡片阴影核心透明度与外缘渐隐                                  | `tests/e2e/shadows.spec.ts`         |
| 媒体错误恢复、播放位置、暂停意图、原生右键                    | `tests/e2e/media-stability.spec.ts` |
| 域名弹层、触屏、短屏、异常文章接口                            | `tests/e2e/edge-cases.spec.ts`      |
| CDN 头像异步加载与 favicon 圆角                               | `tests/e2e/avatar.spec.ts`          |
| 告知确认、跨标签同步、政策入口与滚动                          | `tests/e2e/privacy.spec.ts`         |

修复行为缺陷时，先让对应回归在旧实现失败，再确认修复通过。检查新增用例是否复现了用户问题，避免仅检查实现细节或为通过测试放宽有效断言。冻结原型、图片与摘要不得随正式代码一并修改。

## 手工检查

- 在桌面、390px、320px 以及短横屏检查布局、动画、内容底边、页脚收纳和媒体操作；涉及断点时检查边界两侧，设备安全区模拟与实体设备结果分别记录。
- 外部资源加载或失败不阻塞正文入场；入场后页面保持可操作，媒体缓冲不得撤下已有画面。换页和隐藏 UI 不重选视频，并检查播放器休眠、键盘与触屏操作。
- 检查“更多”内容可滚动到每个链接，打开和关闭有动画；独立政策页仅正文滚动，底部告知保留 12px 外间距且不移动主页布局。
- 不拦截网络时另查三个视频、随机兜底图、MiSans、头像、文章接口及统计请求；外部服务故障与页面代码问题分别判断。不要把确定性 CI 的成功描述为外部服务验证。

## 发布检查

正式域名备案、平台 301/404、缓存头和统计接收情况需要在实际托管环境验证。构建成功、CI 成功和发布成功分别判断，部署步骤及回滚方式见 [部署说明](deployment.md)。
