## 部署工具链修正

用户提供的部署日志确认 EdgeOne 无法切换到原配置的 Node.js 24.22.1，平台支持的最高版本为 24.18.0。现将 `edgeone.json#nodeVersion` 与 `.nvmrc` 同步为该版本，CI 也使用它；`package.json#engines` 保留兼容范围。
